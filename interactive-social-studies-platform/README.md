# تحدي الدراسات الاجتماعية

منصة اختبار تفاعلية للصف السادس الابتدائي — مدرسة العروس الابتدائية.
تعمل بتكامل تلقائي مع قاعدة بيانات **Neon (PostgreSQL)** عند النشر على **Vercel**.

## التشغيل المحلي

```bash
npm install
npm run dev
```

> في المعاينة المحلية يعمل الموقع تلقائيًا بوضع «التخزين المحلي» دون خادم.

## النشر على Vercel + Neon (التكامل التلقائي)

1. **أنشئ قاعدة Neon** (مجانًا):
   - ادخل إلى [neon.tech](https://neon.tech) وأنشئ مشروعًا جديدًا.
   - انسخ **Connection String** (تبدأ بـ `postgresql://...`).

2. **ارفع المشروع إلى GitHub** ثم اربطه بـ Vercel (Add New → Project → Import).
   - Vercel يتعرف تلقائيًا على Vite (الواجهة) ومجلد `api/` (دوال Serverless).

3. **أضف متغير البيئة** في Vercel:
   - Project → Settings → Environment Variables
   - الاسم: `DATABASE_URL` — القيمة: رابط Neon الذي نسخته.

4. **Deploy** — الجداول (`results`, `teachers`, `sessions`, `settings`) تُنشأ تلقائيًا عند أول طلب، دون أي خطوة إضافية.

> **طريقة أسرع:** من لوحة Vercel → Storage → Create Database → **Neon** → اربطه بالمشروع، وسيُضاف `DATABASE_URL` تلقائيًا.

## لو ظهرت شارة «تخزين محلي» في لوحة المعلم

1. تأكد أن `DATABASE_URL` مضبوط في Vercel → Settings → Environment Variables.
2. اضغط **Redeploy** (النشر السابق لا يرى المتغيرات الجديدة).
3. من داخل اللوحة اضغط زر **«إعادة الاتصال»** — سيوقظ قاعدة Neon (قد تكون نائمة في أول تشغيل) ويُفعّل المزامنة.

دخول المعلم: كلمة المرور **139613** فقط، وتُغيّر من داخل اللوحة.
شهادة الإنجاز تُمنح تلقائيًا فقط للطلاب الذين يحققون **75% فأكثر** (45 درجة من 60)، وتتضمن اسم المعلم **علي عبدالله راجحي** ومدير المدرسة **حسن عبدالله مسودي**.

**تقارير الطباعة** (من لوحة المعلم):
- زر **«طباعة التقرير»**: تقرير جماعي بصيغة A4 يضم ملخص الإحصاءات وجدول所有 النتائج الظاهرة بعد البحث/التصفية، مع التوقيعات.
- زر الطابعة في صف أي طالب: **تقرير فردي مفصّل** يشمل إجاباته سؤالًا بسؤال مع الإجابة الصحيحة عند الخطأ.
- من نافذة الطباعة يمكن اختيار «حفظ بتنسيق PDF».

> **ملاحظة تقنية:** دوال `api/` مولّدة ومكتفية بذاتها (Vercel لا يُضمّن مجلدات `_lib` مع حزمة الدالة).
> المصدر المشترك في `server/core.ts`، وبنك الأسئلة في `src/data/questions.ts`.
> بعد أي تعديل عليهما شغّل: `npx tsx scripts/gen-api.ts` ثم أعد النشر.

## ما يحدث تلقائيًا عند توفر Neon

| الميزة | السلوك |
|---|---|
| نتائج الطلاب | تُحفظ في Neon **أونلاين** وتتزامن بين جميع الأجهزة |
| التصحيح | يتم **جهة الخادم** — الإجابات الصحيحة لا تصل متصفح الطالب إطلاقًا |
| الأسئلة | يستلم الطالب نسخة منقّحة (بلا إجابات)، والمعلم النسخة الكاملة برمز جلسة |
| دخول المعلم | كلمة مرور واحدة فقط: **139613** (مشفّرة بـ scrypt + ملح، جلسة 24 ساعة، وتُغيّر من اللوحة أو عبر `TEACHER_PASSWORD`) |
| بنك الأسئلة والإعدادات | تُحفظ سحابيًا وتُزامَن تلقائيًا على كل الأجهزة كل 20 ثانية |

عند غياب `DATABASE_URL` يسقط الموقع تلقائيًا إلى التخزين المحلي (localStorage) دون أي أعطال.

## الأمان

- لا توجد كلمات مرور أو مفاتيح داخل الواجهة الأمامية — `DATABASE_URL` متغير خادم فقط.
- نقاط القراءة العامة (بدء الاختبار، حالة الاختبار) مفتوحة للطلاب، وكل عمليات الإدارة محمية برمز الجلسة.
- تسليم الاختبار محمي من الاحتساب المكرر عبر `ON CONFLICT DO NOTHING` ومعرّف فريد لكل محاولة.
