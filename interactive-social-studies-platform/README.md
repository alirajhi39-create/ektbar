# تحدي الدراسات الاجتماعية

منصة اختبار تفاعلية للصف السادس الابتدائي — مدرسة العروس الابتدائية.
تعمل بتكامل تلقائي مع قاعدة بيانات **Neon (PostgreSQL)** عند النشر على **Vercel**.

## التشغيل المحلي

```bash
npm install
npm run dev
```

> في المعاينة المحلية يعمل الموقع تلقائيًا بوضع «التخزين المحلي» دون خادم.

## النشر على Vercel + Neon (التكامل التلقائي)

1. **أنشئ قاعدة Neon** (مجانًا):
   - ادخل إلى [neon.tech](https://neon.tech) وأنشئ مشروعًا جديدًا.
   - انسخ **Connection String** (تبدأ بـ `postgresql://...`).

2. **ارفع المشروع إلى GitHub** ثم اربطه بـ Vercel (Add New → Project → Import).
   - Vercel يتعرف تلقائيًا على Vite (الواجهة) ومجلد `api/` (دوال Serverless).

3. **أضف متغير البيئة** في Vercel:
   - Project → Settings → Environment Variables
   - الاسم: `DATABASE_URL` — القيمة: رابط Neon الذي نسخته.

4. **Deploy** — الجداول (`results`, `teachers`, `sessions`, `settings`) تُنشأ تلقائيًا عند أول طلب، دون أي خطوة إضافية.

## ما يحدث تلقائيًا عند توفر Neon

| الميزة | السلوك |
|---|---|
| نتائج الطلاب | تُحفظ في Neon وتتزامن بين جميع الأجهزة |
| التصحيح | يتم **جهة الخادم** — الإجابات الصحيحة لا تصل متصفح الطالب إطلاقًا |
| الأسئلة | يستلم الطالب نسخة منقّحة (بلا إجابات)، والمعلم النسخة الكاملة برمز جلسة |
| حساب المعلم | كلمة المرور مشفّرة بـ scrypt + ملح، وجلسة برمز عشوائي مدته 24 ساعة |
| بنك الأسئلة والإعدادات | تُحفظ سحابيًا وتطبق على كل الأجهزة فورًا |

عند غياب `DATABASE_URL` يسقط الموقع تلقائيًا إلى التخزين المحلي (localStorage) دون أي أعطال.

## الأمان

- لا توجد كلمات مرور أو مفاتيح داخل الواجهة الأمامية — `DATABASE_URL` متغير خادم فقط.
- نقاط القراءة العامة (بدء الاختبار، حالة الاختبار) مفتوحة للطلاب، وكل عمليات الإدارة محمية برمز الجلسة.
- تسليم الاختبار محمي من الاحتساب المكرر عبر `ON CONFLICT DO NOTHING` ومعرّف فريد لكل محاولة.
